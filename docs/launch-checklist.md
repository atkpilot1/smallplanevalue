# SmallPlaneValue — Launch Checklist

**Goal:** Get pilots trying valuations + feedback on BeechTalk, Facebook groups, EAA circles, and marketplace bios.  
**Site:** https://smallplanevalue.com  
**Positioning:** see [competitive-positioning.md](./competitive-positioning.md)  
**Pricing narrative:** A few free valuations to try it; then pay-per-use (~$24 / report or a 5-pack) — not an always-free utility.

---

## Channels (do in order)

1. **BeechTalk** — Use the Feedback tab “Copy for BeechTalk / FB” button, or Post B below. Post in relevant type / for-sale threads; don’t spam.
2. **Facebook groups** — Bonanza, Cirrus, RV / experimental, type clubs. Same blurb + link. Prefer groups you’re already a member of.
3. **X / Facebook Page** — Use share buttons on the Feedback tab; pin Post B on the Page.
4. **EAA / Oshkosh angle** — Emphasize experimental / RV / LSA coverage. If AirVenture timing still fits: AirLogbooks is at Hangar B · Booth 2096 — natural cross-mention.
5. **Trade-A-Plane / Controller forums / marketplace bios** — Short bio + `smallplanevalue.com` in signature or “about” where allowed.
6. **ntailnum.com funnel** — Keep CTA pointing at SPV with UTM (`utm_source=ntailnum`).
7. **Partner cross-post** — Ask AirLogbooks to mention SPV; SPV shows them on the valuation loader tip.

## Ready posts

### Post A — Soft ask for feedback

```
Built a GA valuation tool for the listing in front of you — honest asking / fair-market ranges, no fabricated “sold” prices (GA doesn’t have MLS comps). A few free valuations to try it, then inexpensive pay-per-use if you’re shopping hard. Looking for feedback from pilots — especially BeechTalk and type-club folks.

https://smallplanevalue.com
```

### Post B — Differentiation + trusted partner (recommended)

```
FindAircraft helps you find the plane. Windsock sells a paid valuation report. SmallPlaneValue is the negotiation brief for the listing in front of you — asking range, fair market, buyer target, and a pre-buy checklist — without pretending GA has MLS sold prices.

Try a few valuations free, then pay per report when you need more (about $24, or a 5-pack if you’re comparing several birds).

Trusted partner: AirLogbooks (https://airlogbooks.com) — digitized aircraft logbooks make records easier to verify, help protect value, and often make a plane easier to sell. We handle the price brief; they handle the paper trail.

https://smallplanevalue.com
```

### Post C — Short partner / logbooks (optional)

```
While you’re sanity-checking a listing price on SmallPlaneValue, remember clean digital logbooks protect value and ease of sale. Trusted partner: AirLogbooks — https://airlogbooks.com

Valuations: https://smallplanevalue.com (a few free to try, then pay-per-use)
```
